Abelion Hermes Plugins

Plugins that make their security boundaries explicit.

Standalone plugins for Hermes Agent. Each plugin owns its implementation, docs, tests and E2E suite. CI runs against a pinned Hermes core commit, never against a floating host, and a green run is evidence only for the paths it actually exercised.

Privacy Guard (nebula)

Session-local masking for PII, credentials and paths, held-output redaction, and a fail-closed required mode for the pinned host. No process-wide firewall claim.
