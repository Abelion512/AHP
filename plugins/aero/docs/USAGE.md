# Use Aero

Ask an ordinary question. The assistant uses the bundled skill to select a
supported card when a visual or interaction adds value. Examples:

- Explain this process so I can explore one stage at a time.
- Ask me which direction to explore, with clickable choices and an optional note.
- Compare these sourced quantities visually, keeping exact values and units.
- Give me a checklist that I can mark locally as I work.

Choice controls keep selections local until explicit submit. Flow/chart controls
are local exploration. Only wizard completion persists per owning chat/card;
other state is temporary. Marking a checklist step is not evidence of execution.

See the [catalog and installation](../README.md),
[model authoring guidance](../skills/aero/SKILL.md),
[design and sources](DESIGN.md) and [verification limits](VERIFICATION.md).
Unsupported clients receive a text fallback. Cards never authorize external
messages, purchases, account changes or other work on their own.
