## Summary

Adds `intelligence-ui-abelion`: native, interactive transcript cards for Hermes Desktop/WebApp via a versioned `::ui{...}` directive. Covers `wizard`, `status`, `trace`, `compare`, and `form`; no iframe, no core patch, no model-supplied JS/HTML.

## Files

- `plugins/intelligence_ui_abelion/desktop/plugin.js` — transcript directive component
- `plugins/intelligence_ui_abelion/docs/directive-contract.json` — versioned contract
- `plugins/intelligence_ui_abelion/docs/GENERATIVE_UI_COMPARISON.md` — comparison against ChatGPT DIL, OpenUI, A2UI, json-render, MCP Apps, AG-UI, and thinking-visual patterns
- `plugins/intelligence_ui_abelion/docs/CORE_COMPARISON.md` — why this is an edge plugin, not core
- `skills/intelligence-ui/SKILL.md` — bundled authoring skill
- `e2e/live_webapp_smoke.py` + `e2e/README.md` — live WebApp smoke
- `README.md`, `hermes.json` — registration
