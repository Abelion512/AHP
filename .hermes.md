# .hermes.md — Hermes-specific project rules (hierarchical)

Hermes-specific rules untuk repo ini. File ini diwarisi dari parent ke subdir sampai git root.
AGENTS.md tetap jadi sumber portable untuk agent lain; jangan duplikasi penuh di sini.

## Build & test (scoped)

- Plugin mana pun: ganti `PLUGIN_ID` dengan id katalog, lalu `python -m compileall -q plugins/PLUGIN_ID` dan `python -m pytest plugins/PLUGIN_ID/tests -q` (sinkron CI `.github/workflows/ci.yml`, matrix per plugin). Jalankan hanya plugin yang berubah.
- Perintah spesifik (host pin E2E, test berat yang boleh di-deselect, config) ada di `plugins/PLUGIN_ID/AGENTS.md`; jangan salin ke sini.
- E2E butuh host pin dari `plugins/PLUGIN_ID/e2e/host.json`; jangan jalankan E2E penuh kecuali perlu.
- Dependency audit (CI): `pip-audit -r <file>` bila ada `requirements*.txt` / `plugin-requirements.txt`.
- Post-tool hook `post_tool_call_lint.py` fail-open bila ruff tidak ada.
- Plugin baru wajib punya `AGENTS.md` sendiri sebelum checklist dicentang.

## Style

- Cosmic/Latin naming untuk plugin baru (nebula, nova, aurora, ...). Tanpa suffix -abelion.
- Satu plugin satu folder, satu entri hermes.json, docs trio, tests, e2e bila relevan.
- test data synthetic/local-only, tanpa real credentials.

## Workflow

- Ikuti skill agentic-engineering-workflow untuk Explore-plan-code dan TDD.
- Gunakan large-codebase-navigation skill untuk scoped search dan LSP.
- Gunakan harness-bootstrap skill untuk perubahan harness.
- Parallel work: hermes -w worktree per sesi; delegate_task untuk subagents dalam satu sesi.

## Gotchas

- JANGAN edit ~/.hermes/config.yaml via patch tool. Gunakan hermes config edit/set.
- Pin Hermes core per plugin ada di `plugins/PLUGIN_ID/e2e/host.json` (contoh nebula: lihat `plugins/nebula/AGENTS.md`).
- AGENTS.md adalah portable contract. .hermes.md ini sadece Hermes override.

## PR rationale

Use `.github/PULL_REQUEST_TEMPLATE.md`: What changed, Why merge this now, and Verification must contain substantive answers and evidence. Existing Indonesian headings are supported by the gate.
